# india-rental-market-analytics
Tableau dashboard analysing rental prices across six Indian cities by locality, BHK configuration, and furnishing status.
Real Estate Rental Price Analysis and Market Intelligence

Project Overview

An interactive Tableau dashboard exploring 4,746 rental listings across six Indian cities to understand rental price patterns and property characteristics.

Business Objectives

1. Compare rental prices across cities and localities.

2. Analyze rental prices by BHK configuration.

3. Explore differences by furnishing status.

4. Identify rental patterns that can support better decision-making.

Tools & Technologies

1. Tableau - Data visualization and dashboard development

2. Excel, SQL or Python - Data preparation, where used

Dataset

The dataset includes city, locality, BHK, furnishing status, area type, tenant preference, point of contact, and monthly rent.



Key Deliverables

1. Interactive rental market dashboard

2. City and locality comparisons

3. Furnishing and BHK analysis

4. Data-driven rental market insights

Business Value

This project demonstrates how data visualization can help users compare rental listings and explore factors associated with rental prices.
